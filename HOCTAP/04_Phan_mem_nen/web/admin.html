Questions du jeu (JSON)

Modifie, ajoute, puis « Envoyer ». Les questions sont remplacées en mémoire jusqu'au prochain redémarrage de l'objet. Pour les garder définitivement, colle le JSON dans questions.h et téléverse.


Format d'une question : {"cat":"Mots voyageurs","fr":"…","vi":"…","o":["A","B","C","D"],"r":0,"pfr":"révélation FR","pvi":"tiết lộ VI"} — r est l'index de la bonne réponse (0 à 3). Une question sans 4 options est ignorée.
